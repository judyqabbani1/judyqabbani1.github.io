Shadow of the Past

A narrative-driven, single-player Unity game where the story is revealed through exploration and the environment.

Overview Systems I built Design decisions What I learned

Overview

Instead of linear dialogue, the story unfolds as the player explores: collecting memories and following environmental cues. The first level is a complete prototype that shows the full system design, narrative pacing and gameplay flow in a small space. I’m continuing to build it out.

Systems I built

  • Player controller: smooth movement, jump handling and ground detection, written in C#.
  • Orb-based progression: the game tracks collected orbs, and the first orb opens a gate to the second part of the level.
  • Event-driven UI: the UI listens for changes in the player’s state and updates on its own, with no manual refresh calls.
  • Scene and state management: centralized handling of menus, gameplay and transitions, plus an audio manager for smooth changes between them.
  • Feedback: audio, on-screen feedback and animation wired into interactions to support immersion.

Design decisions

I built each system as an independent component, so new levels, puzzles and progression conditions can be added without touching the core gameplay logic. Because this is a first-level prototype, I focused on getting a clear progression structure in place early. That makes it easy to expand later without the project getting messy.

What I learned

How to design gameplay systems that serve a story: keeping the technical progression structured while letting the narrative feel organic and player-driven.
