Personal project

Quarto

A complete 2D digital version of the Quarto board game, focused on turn-based logic, rule enforcement and game state.

Overview Systems I built Design decisions What I learned

Overview

The goal was to recreate the whole game digitally, including the board, pieces, rules and every win condition, and to do it with a flexible system design. I didn’t add AI opponents or effects on purpose. The focus was getting the rules exactly right.

Systems I built

  • Turn-based game loop that keeps every action in order and blocks input from the player whose turn it isn’t.
  • Board state tracking that knows where every piece is and whether a move is legal, and rejects illegal moves.
  • Win-condition checks after every turn that test whether four pieces in a line share an attribute (shape, size, color or fill).
  • Multiple rule variants supported by the same system.
  • Mouse controls for selecting and placing pieces.

Design decisions

Every rule is evaluated the same way every time, so there are no unclear outcomes. The game supports different rule sets and ways to play while still behaving predictably, with edge cases handled explicitly instead of left to chance.

What I learned

How much small structural decisions early on make later work easier or harder. Building Quarto taught me to think through edge cases, keep the code faithful to the rules, and turn game mechanics into reliable software.
